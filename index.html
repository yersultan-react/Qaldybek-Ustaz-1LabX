Қозғалыс анимациясы

Нүктенің тербелісін нақты уақытта бақылау

x(t) — Координата

x(t) = 2.00·sin(1.57t + 0.00)

v(t) — Жылдамдық

v(t) = 3.14·cos(1.57t + 0.00)

a(t) — Үдеу

a(t) = -4.93·sin(1.57t + 0.00)

E(t) — Кинетикалық және Потенциалдық Энергия

Ek — кинетикалық (жасыл), Ep — потенциалдық (қызғылт), E — толық (ақ)
E = 4.93 Дж
Қысқаша теория
  • Координата: x(t) = A·sin(ωt + φ)
  • Жылдамдық: v(t) = Aω·cos(ωt + φ)
  • Үдеу: a(t) = −Aω²·sin(ωt + φ)
  • Жиілік: f = 1/T, бұрыштық жиілік: ω = 2π/T
  • Максимал жылдамдық: vmax = Aω, үдеу: amax = Aω²
  • Кинетикалық энергия: Ek = ½mv²
  • Потенциалдық энергия: Ep = ½mω²x²
  • Толық энергия: E = Ek + Ep = ½mω²A² = const
Зертханалық тапсырмалар
1) A=3 м, T=2 с енгізіп, vmax мен amax мәндерін тап.
2) Периодты азайтқанда бұрыштық жиілік қалай өзгереді?
3) φ=1.57 енгізіп, cos пен sin графиктерінің айырмашылығын түсіндір.
4) Энергия графигінде Ek максимум болғанда Ep нөлге тең екенін байқа.
